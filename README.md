# SABLOX-PBX

Учебная веб-панель телефонной станции для домашнего музея.

## Версия 0.1
- Внутренние номера 101–106.
- Выбор аппарата-источника и номера назначения.
- Демонстрация вызова и журнал событий.
- Адаптивная панель для телефона.

## Публикация через GitHub Pages
1. Откройте **Settings → Pages**.
2. В разделе Build and deployment выберите **Deploy from a branch**.
3. Branch: `main`, folder: `/ (root)`.
4. Нажмите **Save**.

После публикации панель будет доступна по адресу GitHub Pages вашего репозитория.

## Важно
Это учебный симулятор коммутатора. Он не передаёт голос, не регистрирует SIP-аппараты и не является реальной телефонной АТС. Для настоящих голосовых звонков нужен постоянно работающий сервер с SIP/WebRTC, настройкой сети и безопасной авторизацией.
